# admin-system — 后台管理系统

> 对应 ROADMAP「六、项目实战 · RuoYi」与「七、部署」（难度 🌟🌟🌟🌟 / 重要度 🌟🌟🌟🌟🌟）
> 完成标准：能看懂 RuoYi 源码、完成模块开发；能独立部署 Spring Boot + MySQL + Redis + Nginx 项目

## 目标功能

- 用户 / 角色 / 菜单权限（RBAC）
- 登录认证（Token / Redis 会话）
- 操作日志与系统监控
- 前端管理界面（Vue）

## 技术栈

Spring Boot + MyBatis + MySQL + Redis + Vue + Nginx

## 部署

`deploy/` 目录存放部署脚本与配置（Docker、Nginx、Linux 服务器）。
